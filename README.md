# Aryan Rajput - Portfolio

A modern and interactive developer portfolio built with **Next.js**, **TypeScript**, **TailwindCSS**, and **Framer Motion** showcasing projects, experience, skills, and personal interests through a visually immersive interface.

---

## 🚀 Features

- Modern responsive UI/UX
- Interactive animations with Framer Motion
- Floating glassmorphism navbar
- Project showcase with modal previews
- Life & Stories gallery section
- Optimized dark futuristic aesthetic
- Fully responsive across devices
- Smooth scrolling experience

---

## 🛠️ Tech Stack

- Next.js
- TypeScript
- TailwindCSS
- Framer Motion
- Aceternity UI
- React Icons

# ⚡ Getting Started

Clone the repository:

```bash
git clone https://github.com/aryanraj13/PortfolioProject.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
npm start
```
